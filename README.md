# Upakosh: Untold Story Telling Platform

Upakosh is a safe, anonymous digital space designed for students, corporate professionals, and individuals to share their untold stories of harassment, ragging, depression, and body shaming. Beyond just a community forum, the platform bridges the gap between victims and professional help by providing direct access to medical consultations and emergency police assistance. 

## 🌟 Key Features

* **Anonymous Story Feed:** A safe timeline where users can share their struggles without revealing their identity. Community members can interact using "Like" and "Support" buttons to show solidarity.
* **Medical Assistance Portal:** Direct routing to medical professionals (e.g., Dr. Meghnath Saha, Dr. Anirudhaya Maity, Dr. Raj Chakraborty) categorized by specific concerns:
  * Harassment
  * Ragging
  * Depression
  * Body Shaming
  * Domestic Violence
* **Emergency Police Support:** Geolocation-based tracking to find the nearest police station, along with an interface to document crimes and raise immediate complaints.
* **Dynamic Information Slider:** An automated carousel highlighting motivational quotes and awareness campaigns against ragging and depression.
* **Feedback System:** A dedicated 5-star rating and comment portal to continually improve the user experience.

## 💻 Tech Stack

* **Frontend:** HTML5, CSS3 
* **Scripting & Logic:** Vanilla JavaScript (DOM manipulation, Geolocation API, Event Listeners)

## 📁 Project Structure

* `home.html` / `di.html` - The main landing page featuring the slider and quick access to Doctor/Police emergency modules.
* `post.html` / `story.html` - The community feed where users can read, post, and support untold stories.
* `s.html` / `support.html` - Information about the platform, mission, and the developer team.
* `feedback.html` - The user feedback and rating form.
* `singup.html` - The authentication portal for users to log in or register.
* `p.html` / `administretive.html` - The administrative dashboard.

## 🚀 How to Run Locally

1. Clone this repository to your local machine.
2. Ensure you have an active internet connection (the project uses external image URLs and web fonts).
3. Open `home.html` in any modern web browser to view the application. No local server setup is required for the frontend UI.
